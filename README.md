# クラフトワールド 3D — ブラウザ完結型 3Dボクセル・サバイバル (v0.13.2)

Three.js だけで動く「マインクラフト風」3Dサバイバルゲームです。
**PC（キーボード＋マウス）とスマホ／タブレット（タッチ操作）の両方**に対応し、
サーバーなしの静的サイトとして完全に動作します（データは端末の localStorage に保存）。

**バージョン規則**: `v0.a.b`（a=大規模変更、b=修正・小追加。v1 は公開版のため当面 v0 系）。
現バージョンは画面左上に常時表示。更新履歴は `js/version.js` の `GameVersion.CHANGELOG` を参照。

## v0.13.2 — エンド次元＆エンダードラゴン
- **エンド次元を実装**：虚空に浮かぶエンドストーンの浮島群（中央の大島 `d0<76` ＋平坦なボスアリーナ `d0<14`、外縁の小島バンド 90-220）。黒い星空の空（`SKY_END 0x0a0812`、星の不透明度0.9・薄い霧・daylight 0.5 固定）で天候は発生せず、時計表示は「🐉 エンド」。中央島には黒曜石柱リング（8本・高さ6-14・先端にクリスタル台座）、外縁の島にはシュルームライトが灯る
- **エンドポータル部屋**：オーバーワールド地下の新構造物（どのバイオームでも約6%）。丸石/苔むした丸石の9×9×5の遺跡に5×5のエンドポータルフレーム＋内部3×3のエンドポータル（床下は黒曜石板）。番人ゾンビ2体とダンジョン級の宝チェストつき
- **転移/セーブ**：`switchDimension` を3次元対応に汎用化（`dimCache` で次元ごとに独立スナップショット）。エンドへの転移は常に中央島（0,0・1:1スケール）、帰還はエンドポータル（オーバーワールド側に帰還ポータルを自動生成）。セーブに `dims.end` を追加し、エンドでセーブ&終了しても次回はエンドから再開（`_resumeEnd`、後方互換あり）
- **虚無落下**：エンドの島から落下（y<-6）すると0.5秒ごとに4ダメージ。エンド/ネザーで死亡した場合はリスポーン時に自動でオーバーワールドへ帰還
- **エンダードラゴン（ボス）**：中央島にHP200のボスが出現（`noDespawn`・`boss` フラグ）。3フェーズ飛行AI：**周回**（アリーナ上空を旋回）→ **急降下**（咆哮 `Sound.roar` と共にプレイヤーへ突撃、接触ダメージ8＋打ち上げ）→ **上昇** を繰り返す。翼の羽ばたき・体の上下動アニメーション、被弾時は紫にフラッシュ
- **ボスバー**：ドラゴン戦中はHUD上部に紫色のボス体力バーを表示（`UI.setBossBar(name, frac)`、CSS グラデーション）。討伐・次元移動で自動的に消える
- **討伐報酬**：(1) 咆哮＋雷鳴の演出とトースト通知（`onDragonDefeated` コールバック）(2) ダイヤ3/エメラルド4/金インゴット4/アメジスト・水晶の欠片の計13個を**インベントリへ直接付与**（ワールドドロップがポータルを上書きするバグを根本回避）(3) 中央島に**帰還ポータル**（岩盤基盤つき3×3）が開く (4) 脇の岩盤台座にトロフィー「**ドラゴンの卵**」が出現（`lastExitPortal` に座標記録）
- **新ブロック5種**（ID 176-180）：エンドストーン / エンドポータルフレーム（破壊不可） / エンドポータル（星空の発光ブロック） / ドラゴンの卵 / クリスタル台座
- **検証**：E2Eテスト25件全パス（ポータル往復・ドラゴンライフサイクル・報酬・虚無ダメージ・次元間編集の永続性）

## v0.13.1 — ネザー次元
- **ネザー次元を実装**：オーバーワールドと独立したワールドデータ（地形・編集・チェスト・かまど・作物・ドア）を持つ新ディメンション。`new World(seed, scene, dimension)` の第3引数で次元を指定し、同一シードにオフセット（`1013904223`）を加えてオーバーワールドとは別の地形を生成。暗い赤黒い空・霧（`SKY_NETHER`）、常時薄暗い照明（daylight 0.55 固定）で天候は発生しない。時計表示は「🔥 ネザー」
- **ネザー地形**：ネザーラックの大地と**溶岩海**（海面Y=30に溶岩、`SEA-9+base*34` の起伏で海と陸が入り混じる）、**ソウルサンド渓谷**（ノイズで局在化したソウルサンドの地表）、チーズ/スパゲッティ洞窟、天井はネザーラック+岩盤（y=WH-1）。**グロウストーンの塊**（天井・光源）、**玄武岩の柱**、溶岩湖を生成。地表はネザーラック/ソウルサンド/マグマ/玄武岩
- **ネザーの鉱石**：**ネザー金鉱石**（金塊4個ドロップ）と**ネザー水晶鉱石**（水晶の欠片2個ドロップ）が鉱脈状に生成。新アイテム**金塊**は9個で金インゴット1個と相互変換可能
- **ネザーポータル**：黒曜石の4×5枠（内部2×3以上）を組み、内部に**火を点ける**と開通（`findPortalFrame` がX/Z両方向の枠を検出、`ignitePortal` でポータルブロック充填）。ポータルブロック（新ブロック・紫色の揺らめく発光・設置不可）に**触れると転移**。座標は**1:8スケール**でリンク（オーバーワールド8ブロック＝ネザー1ブロック）。転移先に既存ポータルがなければ安全な地面に自動生成（`findOrBuildReturnPortal`：半径40で既存ポータルを全層探索し増殖を防止、なければ `findNetherGround` で溶岩海上の地面を探し `buildPortalAt` で建造）。6秒のクールダウンで即時往復を防止
- **次元別セーブ**：セーブデータに `dims:{overworld,nether}` を追加し、両次元の編集状態を個別に保存。ネザーでセーブして終了しても次回はネザーから再開（`_resumeNether`）。セッション中は `dimCache` で非アクティブ次元を保持。旧形式（v0.13以前）セーブとの後方互換あり（トップレベルのedits等はオーバーワールド扱い）
- **ネザーのモブ**：敵モブ（ゾンビ・スケルトン）のみがネザーラック/ソウルサンド/玄武岩の地表にスポーン
- **バグ修正**：ネザーの天井ベース岩を地面と誤認してポータル生成が範囲外Yで失敗する境界バグ（`findNetherGround` のフォールバック高さを `SEA+2..SEA+8` に制限＋`buildPortalAt` に `WH-5` クランプ追加）、ポータル枠検出がZ方向の枠に非対応だった問題（`findPortalFrameAxis` で両軸対応）を修正。ポータル音（`Sound.portal`）追加。E2Eテスト（往復転移・帰還ポータル生成・編集データ復元・増殖防止）20件全パス

## v0.13 (major) — 新バイオーム・天候・構造物
- **天候システム**：雨・雷雨・雪。100-260秒の晴れと30-90秒の降水が交互に訪れ、降水の20%は雷雨に。**バイオームで降水の種類が変わる**（寒冷＝雪原/タイガ/高山/氷山→雪、砂漠/メサ/火山→降水なし、それ以外→雨）。降水はプレイヤー周辺を落下するパーティクル（雨は速く青く斜めに、雪はゆっくり白く揺れながら）と環境音（雨のループ音・雷の轟音、`Sound.rainStart`/`thunder`）つき。雷雨の空は暗転し霧が濃くなり、落雷で空が一瞬白く閃く。時計表示に天候アイコン（☀🌧⛈🌨）
- **落雷による火災**：雷雨の落雷は地表に炎ブロック（新ブロック・発光）を点ける。炎は雨で消え、時間経過でも燃え尽きる
- **氷山バイオーム**：寒冷な海（temp<-0.14）は凍った海面の氷山バイオームに。青氷・氷塊の浮氷が散らばり、**巨大な氷山構造物**が浮かぶ（水上の峰＋それより大きな水中の基部。青氷の芯＋氷塊の外殻、頂上は雪。リージョン配置 約12%）
- **きのこ島バイオーム**：極めて希少（rare>0.42）な島バイオーム。地表は菌糸、**巨大キノコ**（赤＝5-7高の傘、茶＝7x7円盤）が林立し、専用モブ**ムーシュルーム**（赤い牛・背中にキノコ）がスポーン
- **メサ（荒野）バイオーム**：高温・乾燥の希少地域に赤いテラコッタの層状地形。深度に応じた5色のテラコッタ縞模様の地層、地表は赤砂で枯れ木が点在
- **洞窟バイオーム**：(1) **繁茂した洞窟**＝中層の帯で洞窟床が苔むし、苔床に草・小キノコ、天井から**グロウベリーの蔓**（発光・食用）が垂れ下がる (2) 鍾乳洞の大型化は v0.10.4 の深度補正で実現済み (3) **ディープダーク**＝深層（y<10）の局在した帯で石がスカルクに置き換わり、稀に発光するスカルク触媒が混じる
- **海の構造物**：(1) **沈没船**＝海底に沈んだ木造船（V字底・折れたマスト）に宝のチェスト (2) **海底神殿**＝プリズマリンの尖塔神殿。シーランタンの灯り、中央に金縁の黒曜石の核と宝のチェスト (3) **水中遺跡**＝苔むした石レンガの廃墟に宝のチェスト。深海にリージョン配置（約12%）
- **新ブロック20種**（ID 153-172）：積雪層/氷塊/青氷/菌糸/キノコの柄/赤・茶キノコブロック/テラコッタ5色/赤砂/枯れ木/グロウベリーの蔓/スカルク/スカルク触媒/ダークプリズマリン/金縁の黒曜石/炎（全種テクスチャ付き、クリエイティブで入手可能）。新アイテム：雪玉・グロウベリー（食用）
- **デバッグ表示**：バイオーム名にメサ/きのこ島/氷山を追加（日本語表示、`displayBiomeAt` に氷山の海列判定を追加）

## v0.12.1 の修正 — モブスポーン修正・海の生物のリアル化・段差スムーズ上昇
- **モブがスポーンしない問題を修正**：v0.12 で海の負側だけを深くし陸側の上昇を据え置いたため、陸地の約49%が `h<=SEA+1` の「湿った砂浜」（地表がバイオーム無視で砂/泥/粘土に強制）に偏り、草地が陸の31.5%にまで減少していた。陸側のベース上昇を強化（`c²×26→c²×75 + c×8→c×30`）して内陸を隆起させ、草地を 43.9% に回復（検証：日中パッシブスポーン成功率 175→199/200、地表に草・pumpkin・melon も復活）
- **水生スポーンロールの無駄を解消**：陸地の真ん中でも 55% の確率で水生生物を試行して必ず失敗し、パッシブ枠を食い潰していた。候補列が有効な海である場合のみ水生を試行
- **海の生物の挙動をリアルに**：魚＝ゆったり回遊＋時々ダッシュ（バースト＆コースト）、熱帯魚＝小刻みに素早く方向転換し砂底近くをホバリング、イルカ＝速く中層を泳ぎときどき海面で跳躍（ブリーチング）して弧を描き体を傾ける、亀＝ゆっくり回遊し甲羅をロール、貝＝海底で殻を開閉（プレイヤーが近づくと閉じる）
- **段差のスムーズ上昇**：モブの段差処理が `vel.y=7.4` で上向きに発射して弧を描く「ガクッと跳ねる」動きだったのを、1段の高さまで短時間で補間して持ち上げる方式に変更（Minecraft のオートステップ相当）。プレイヤーのオートジャンプも即座ワープから滑らかな補間に変更

## v0.12 の新機能 — 深海・海溝・暖かい海・海の生物
- **海の深化**：大陸性マスクに三乗項（`c³×900`）を加え、深海は岩盤直上（Y=2）まで深く沈む（最深28ブロック。従来は最大16程度＝2倍以上）
- **海溝**：リッジノイズ（`1-|n|>0.930`）で沖合の深海（大陸性 `c<-0.16`）に細く深い海溝を生成。大洋性ほど深くなり最深で岩盤に到達（検証：533列、最深深度28）
- **新バイオーム「暖かい海」**：浅瀬（海面下8ブロック以内）の温暖海域（temp>0.14）に出現。砂底に**サンゴ4色**（赤/青/ピンク/黄、ID 148-151）と**海草**（ID 152）が生い茂る（検証：50チャンク、サンゴ2112+海草479ブロック）
- **海の生物5種**：魚・熱帯魚・貝・イルカ・カメ。魚は浅瀬に群れ、熱帯魚は暖かい海の砂底付近、貝は海底に静止、イルカは中層を活発に泳ぎ、カメは海面近くを回遊。全種に水生専用の泳ぎ物理（浮力・上下の漂い・尾びれ/ひれのアニメーション）。魚・イルカはプレイヤーが近づくと逃げる
- **スポーンの棲み分け**：陸の動物は海面以上の列にのみスポーンし、海の列には水中生物のみがスポーン（水中に豚や牛が湧かない）

- **鉱石**：石炭・鉄・金・ダイヤ・**アメジスト**（深さで出現率が変化）、砂利、岩盤（最下層は破壊不可）
- **描画**：面カリング＋アンビエントオクルージョン＋空の見え方による陰影焼き込み、半透明の水、霧
- **昼夜サイクル**（1日=10分）：太陽・月・星、空色と光量が連続変化、夕焼け表現
- **砂・砂利の落下**、**松明の光**（近傍をポイントライト化）

### サバイバル
- **体力（♥×10）／満腹度（🍖×10）／酸素（水中）** の3ゲージ
- 空腹による衰弱、満腹時の自然回復、**落下ダメージ・溺水・サボテンダメージ**
- **死亡 → リスポーン**（ベッドで寝るとリスポーン地点を変更）
- **モブ**（全7種）
  - **敵対**：ゾンビ（追跡・攻撃・朝日で焼ける）、**スケルトン**（距離を保って攻撃、骨をドロップ）
    → **夜間と洞窟などの暗所にスポーン**
  - **動物**：ブタ（生の豚肉）、ヒツジ（羊毛）、**ウシ（生の牛肉）**、**ニワトリ（生の鶏肉）**
  - **村人**（v0.8）：村にスポーンする非敵対モブ。茶色ローブと大きな鼻、距離デスポーンしない
  - ノックバック、逃走AI、遠距離での自動デスポーン、進行方向を向く移動
  - v0.8: 動きを滑らかに（角度補間・速度比例の歩行スイング）
- **戦闘**：手／剣／道具でダメージが変化、攻撃クールダウン

### 農業
- **作物4種**：小麦・米・トウモロコシ・トマト（成長段階ブロックで見た目が変化）
- **クワ**（木・石・鉄・ダイヤの4ティア）で草／土を**耕地に耕す**、水に隣接すると湿った耕地に
- **種**は草や葉の破壊でドロップ。耕地に植えると時間で成長（空の下だと速い）
- 成熟した作物を破壊すると収穫（小麦→パンへクラフト）

### ブロック操作
- **採掘**：ブロック硬度 × 道具の適正／ティアで採掘時間が変化、進行表示付き
- 適正ツールでないとドロップしない鉱石（例：鉄鉱石は石ツルハシ以上）
- **設置**：プレイヤー・モブに重ならない位置のみ、水中にも設置可
- **ドロップアイテム**：物理挙動＋吸い寄せ＋自動取得、破壊パーティクル

### アイテム・クラフト
- **インベントリ**：ホットバー9＋メイン27スロット、スタック管理、道具の耐久バー
- **クラフト**：手持ち2×2／**作業台で3×3**（形状あり・形状なしレシピ対応）
- 主なレシピ：木の板 / 棒 / 作業台 / **かまど** / 松明 / **チェスト** / **ベッド** / 本棚 /
  各種ブロック圧縮 / **木・石・鉄・ダイヤの ツルハシ・斧・シャベル・剣・クワ**
- **かまど**：燃料を消費して精錬（丸石→石、砂→ガラス、鉄→鉄インゴット、金→金インゴット、
  原木→石炭、**生の牛肉→ステーキ、生の鶏肉→焼き鳥**、生の豚肉→焼き豚）
- **チェスト**：27スロットの保管庫（破壊すると中身をドロップ）
- **食事**：リンゴ／豚肉・**牛肉**・**鶏肉**（生・焼き）／**パン**
- **ベッド**：夜に使うと朝までスキップ＋リスポーン地点を設定（近くに敵がいると寝られない）

### 操作・UI・その他
- **PC**：WASD移動 / Space ジャンプ / Shift スニーク（落下防止）/ Ctrl or R ダッシュ /
  左クリック採掘・攻撃 / 右クリック設置・使用 / ホイール・1〜9 でスロット選択 /
  E インベントリ / Q ドロップ / Esc メニュー / F3 デバッグ表示
- **モバイル**：左スティック移動（最大倒しでダッシュ）／右ドラッグ視点／
  ジャンプ・採掘・設置・スニーク・ダッシュ・インベントリのボタン／**タッチデバイスではUI常時表示**／
  **1ブロックの段差はオートジャンプ**
- **ステータス表示**：FPSと現在座標を画面に常時表示（右上）
- 手持ちアイテムの一人称表示とスイングアニメーション
- **効果音**：WebAudio によるプロシージャル生成（採掘・設置・被弾・取得・足音・クラフト・朝）
- **セーブ**：30秒ごと＋タブ非表示時＋終了時に自動保存、「つづきから」で再開
- 設定：描画距離（2〜6チャンク）、視点感度、タッチUIの表示切替

## 3. データモデルと保存先

保存はすべてブラウザの **localStorage**（端末ローカル）です。

| キー | 内容 |
|------|------|
| `craftworld3d_save_v1` | ワールドのセーブデータ |
| `craftworld3d_settings` | 描画距離・感度・タッチUI設定 |

セーブデータ構造:

```jsonc
{
  "seed": 123456789,           // ワールドシード（地形は都度再生成）
  "time": 0.42,                // 時刻 0..1 (0 = 朝6時)
  "dimension": "overworld",    // v0.13.1: 現在の次元 ('overworld' | 'nether')
  // トップレベルの edits 等はオーバーワールドのデータ (v0.13以前との後方互換)
  "edits": { "12,34,-5": 4 },  // プレイヤーが変更したブロックのみ差分保存 "x,y,z": blockId
  "furnaces": { "x,y,z": { "input": {...}, "fuel": {...}, "output": {...}, "burn": 0, "progress": 0 } },
  "chests":   { "x,y,z": [ {"id":"stone","count":64}, null, ... ] },   // 27スロット
  "crops":    { "x,y,z": { "crop": "wheat", "stage": 2, "progress": 45 } },  // 植えた作物
  // v0.13.1: 次元別データ。ネザーは独立した edits/furnaces/chests/crops/doors を保持
  "dims": {
    "overworld": { "edits": {}, "furnaces": {}, "chests": {}, "crops": {}, "doors": [] },
    "nether":    { "edits": {}, "furnaces": {}, "chests": {}, "crops": {}, "doors": [] }
  },
  "player": {
    "pos": [x, y, z], "spawn": [x, y, z], "yaw": 0, "pitch": 0,
    "health": 20, "hunger": 20, "saturation": 5, "air": 20,
    "inv": [ {"id":"wooden_pickaxe","count":1,"dura":60}, null, ... ],  // 36スロット
    "selected": 0, "gameMode": "survival", "flying": false
  }
}
```

- **アイテムスタック**: `{ id: アイテム名, count: 個数, dura?: 残り耐久 }`
- **ブロック**: `js/blocks.js` の `BLOCKS[id]`（硬度・適正ツール・必要ティア・ドロップ・描画タイル）
- **作物**: `js/crops.js` の `CropManager`。ステージブロックとの整合を毎フレーム検証し、
  耕地が失われた作物は除去
- **地形データ**: メモリ上のみ（`Uint8Array(16*64*16)`／チャンク）。シード＋差分から常に再現

## 4. ファイル構成

```
index.html            ゲーム本体（HTML構造とUI）
css/style.css         HUD・インベントリ・タッチUIのスタイル
js/noise.js           シード乱数 + Perlinノイズ
js/textures.js        テクスチャアトラスをコードで生成（外部画像ゼロ、103タイル）
js/blocks.js          ブロック定義 / アイテム定義 / クラフト・精錬レシピ
js/collision.js       ボクセルAABBスイープ衝突判定（※blocks.jsの後に読み込むこと）
js/crops.js           作物マネージャー（植え付け・成長・収穫・保存）
js/inventory.js       インベントリ・クラフト判定・かまどロジック
js/world.js           チャンク生成 / バイオーム / メッシュ化 / レイキャスト / セーブ用差分
js/player.js          プレイヤー物理・当たり判定・サバイバルステータス
js/entities.js        ドロップアイテム・モブ（ゾンビ/スケルトン/ブタ/ヒツジ/ウシ/ニワトリ/村人）
js/audio.js           WebAudio 効果音
js/ui.js              HUD・インベントリ・かまど・チェストUI
js/input.js           キーボード／マウス／タッチ入力
js/main.js            ゲームループ・昼夜・採掘設置・農業配線・セーブ・メニュー
js/test-logic.js      自動ロジックテスト 168項目（開発用）
test-logic.html       同上の実行ページ
```

> ⚠️ **スクリプトの読み込み順が重要**：`collision.js` は評価時に `Blocks` を参照するため、
> 必ず `blocks.js` の**後**に読み込む。順序を崩すと `Blocks is not defined` で
> 全フレームの物理が停止し「操作が全く効かない」状態になる（過去に発生・修正済み）。
